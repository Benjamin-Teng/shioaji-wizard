# shioaji-wizard

> **一般使用者請到下載頁：<https://benjamin-teng.github.io/shioaji-wizard/>**
> （提供 Windows 安裝程式與 macOS 磁碟映像，免裝 Python）。以下為開發文件。

永豐 Shioaji 開通測試精靈是本機桌面工具，依序引導使用者設定金鑰、模擬下單、
驗證正式環境與體驗 Shioaji Pro。設定檔 `.env` 可由 Shioaji Pro 直接載入。

## 畫面行為

- **桌面視窗**：Windows 啟動時依螢幕工作區最大化。設定金鑰的主要按鈕移到同一列，
  正式環境的憑證提示集中在第三步。
- **步驟進度**：同一次開啟中，各測試的通過狀態保留在左側。切換設定檔或修改金鑰
  會重新驗證。只變更憑證時，模擬下單的通過狀態保留。
- **美股複委託模擬測試**（Shioaji 1.8.0）：在 A 的「加測市場」勾選「美股複委託」。
  這組 API Key 需要勾選複委託帳戶及交易權限。A6 檢查帳戶，A7 送出 AAPL 1 股、
  180.25 美元的模擬限價買單，有收到接受回報才算通過。若補查後仍顯示「待確認」，
  請先到模擬環境查閱委託紀錄。結果只驗證模擬委託。
- **金鑰與憑證**：四欄（API Key、Secret Key、憑證密碼、憑證檔＋「瀏覽…」）。
  輸入框顏色＝儲存狀態（綠＝已存、黃＝缺；一開始打字就還原預設、清空又回
  綠／黃）。標籤前的圓圈＝最近一次 A／B 對該欄的驗證結果（✓ 通過／✗ 卡在
  這欄；未驗或改過尚未再驗就空白）。更新過的欄位在涵蓋它的測試跑完前一律
  不標（A 只涵蓋金鑰，B 才涵蓋憑證密碼／憑證檔；B4／B6 一律在登入前先離線
  查憑證檔與到期日（B6 通過時說明欄也列出到期日與剩餘天數，日期以台灣時間
  顯示），已過期判失敗、30 天內到期提醒；伺服器端 `stale` 記錄，
  重整不會倒回）。
- **金鑰鎖定**：A1／B1 通過且之後沒改 → API Key／Secret Key 鎖定（Secret
  Key 只會生成一次，不給誤觸機會），要換按「解鎖修改」；鎖定中伺服器拒絕改
  金鑰（409）。按下解鎖後兩欄的 ✓／✗ 先拿掉；開始測試或測試跑完就結束解鎖
  狀態。**檢核單每次按 A／B 都會整個清空、只留這一次的結果**（E 開頭的
  `.env` 檢查項是當場重算的，會保留），金鑰鎖定因此只反映最近一次登入結果；
  切換帳號（見下）同樣會清空檢核單並把金鑰視為未驗證。
- **瀏覽…**：Windows 原生檔案對話框，以 TopMost＋工作列可見的隱形 owner 視窗
  開啟（否則會壓在 app 後面、工作列沒項目）；PowerShell 輸出強制 UTF-8
  （中文路徑不會亂碼）。
- **A／B 按鈕**各附用途說明。A 的「加測市場」可勾選期貨／選擇權和美股複委託，
  B 可各自加查期貨／選擇權和美股複委託帳戶的簽署狀態（B3／B7），只查詢、不下單。
  A 執行前檢查台股與期貨的模擬時段
  （週一至週五台灣時間 08:00–20:00，18:00 後限台灣 IP）。
- **執行紀錄**：子行程逐行輸出（即時遮罩金鑰值與身分證字號），末尾是
  `═══` 框線的文字總覽；**檢核單**表格列每一項 ✓／✗／－ 與原因（每次按
  A／B 先清空再只列這次跑的項目），原因裡的永豐簽署頁網址可點（走
  `/api/open` 白名單、系統瀏覽器開）。
- **憑證到期日（B6）**：在 Windows 上直接離線讀憑證檔（不連網、不需要登入或
  簽署成功），B4（憑證檔存在）與 B6 一律排在登入前先做，B5 憑證啟用失敗也照樣
  顯示到期日；密碼錯、憑證檔損毀／格式不對會分開說明原因。B5 失敗時會多附一句
  離線診斷（憑證檔與密碼本身可讀、到期日；若憑證主體含身分證字號且與登入帳號
  不同人會明講，字號打碼）。非 Windows 或系統缺 PowerShell 時自動退回原本連線
  查詢的作法。
- **匯出除錯紀錄**：在程式工作資料夾產生 `shioaji_wizard-debug-<時間>.log`
  （版本、遮罩後 .env、檢核單、最近一次輸出、app.log／shioaji.log 尾段；金鑰
  值全文遮罩、身分證字號只留頭尾），並在檔案總管選取它。
- **使用說明**是畫面內彈窗。
- 殼：一律 `--disable-extensions --disable-sync`；關窗即收攤（job 執行中
  會先殺子行程；子行程另有 120 秒無輸出／10 分鐘總逾時）。

## 設定檔與憑證

- 每次啟動從「設定金鑰」開始。可用 Windows 原生對話框開啟既有 `.env`，
  或選擇新檔案的資料夾。偵測到 eKey 時，預設使用券商憑證所在資料夾，
  否則使用 `%USERPROFILE%\.shioaji-pro\.env`。
- 「正式環境驗證」可用 Windows 原生對話框指定憑證檔。既有可攜版的設定檔可直接開啟。
- 金鑰設定完成後，可在左側「忘記設定檔.env在哪嗎?」複製路徑。第一次完成模擬下單
  驗證後，建議等待 30 分鐘讓系統建立 API 授權。正式環境驗證通過後，
  第四步會帶你前往 Shioaji Pro。第一次登入時請用「載入設定檔（.env）」沿用同一份設定。

## 安全與免責聲明

- 本軟體為個人開發的開源工具，**非永豐金證券官方軟體**，與永豐金證券無任何
  隸屬或合作關係。
- 金鑰只在使用者電腦與永豐官方 API 之間傳輸：後端只綁 127.0.0.1（Host／
  Origin 守衛擋 DNS rebinding 與 CSRF、無 CORS），金鑰不進 argv／環境變數／
  URL／瀏覽器儲存，API 只回遮罩值；子行程從 `.env` 讀金鑰後交給永豐官方
  shioaji SDK（Rust 編譯，reqwest＋rustls，未發現關閉憑證驗證）連永豐伺服器。
  本軟體不會把金鑰、憑證或帳號資料送到永豐以外的伺服器。唯一的第三方連線：
  週一～五 18:00–20:00 呼叫 `/api/window` 時向 `ipinfo.io` 查公網 IP 所屬國家
  （永豐該時段限台灣 IP）：ipinfo.io 會收到使用者公網 IP 並回傳 IP／國家，
  不會送出金鑰、憑證、密碼或帳號資料。
- 金鑰用途僅限「模擬環境連線測試（A：`simulation=True`，只在模擬環境下單）」
  與「正式環境憑證連線測試（B：只登入與查詢，無任何下單呼叫）」。
- 金鑰與憑證由使用者自行保管（`.env`／`Sinopac.pfx` 為明文檔案）；本軟體與
  開發者不負任何金鑰／憑證保管責任。
- 本軟體按「現狀」提供，不提供任何明示或默示之擔保；因使用本軟體、金鑰或
  憑證外洩、帳戶操作、永豐服務或規則變更所造成之任何損失（含交易損失），
  開發者概不負責。使用即表示同意以上條款。完整條文同時放在程式內「使用說明」、
  bundle 的 `README.txt` 與下載頁。

## 開發

```bash
uv sync
uv run python -m shioaji_wizard --no-shell --port 8765 --root <資料夾>   # 起服務，不開殼
uv run python -m shioaji_wizard --root <資料夾>                          # 有殼（開 Edge/Chrome --app）
uv run pytest -q
uv run ruff check src tools tests && uv run ruff format src tools tests
uv run ty check src tools
uv run --with pillow python tools/make_icon.py   # 重新產 static/favicon.ico（自製印章圖）
```

`--root` 是程式工作資料夾，用來放執行紀錄和最近選擇。測試子行程透過
`SJ_PROFILE_DIR` 讀取目前選用的 `.env`。正式安裝版的工作資料夾位於安裝目錄的
`data` 子目錄。QA 使用隔離工作資料夾與測試資料。

## Windows 安裝檔（NSIS）

```powershell
uv run python tools/build_bundle.py --verify --makensis <makensis.exe 的絕對路徑>
```

- 預設產出單一 `dist/shioaji-wizard-setup.exe`。安裝在目前使用者的
  `%LOCALAPPDATA%\ShioajiWizard`，從「開始」選單開啟。
- 安裝程式內含 CPython、Shioaji SDK 及其他執行依賴。安裝檔排除金鑰、憑證與執行紀錄。
- 升級與移除依照出貨清單清理程式檔。設定檔、憑證和工作資料可保留。
- `--verify` 在隔離目錄測試安裝、啟動、本機 API、SDK 版本、重裝與解除安裝。
- `--zip` 可另建開發驗收用的可攜壓縮檔。

## macOS 安裝檔

分別在 Apple 晶片和 Intel 的 macOS 建置並驗證：

```bash
uv run --locked --python 3.12.13 python tools/build_macos.py --verify
```

- 下載對應晶片的 `.dmg`，將 Shioaji 測試精靈拖到「應用程式」。
- 執行資料在 `~/Library/Application Support/ShioajiWizard`。新建設定檔預設在
  `~/.shioaji-pro/.env`。
- 首次開啟若被 macOS 攔下，請確認檔案來源與校驗碼，再依 Apple 的
  [開啟安全性設定](https://support.apple.com/zh-tw/102445)操作。
