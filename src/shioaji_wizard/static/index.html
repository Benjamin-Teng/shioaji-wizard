      使用說明

      從設定金鑰開始，跟著左側四個步驟完成開通驗證。

      1. 設定金鑰

        有設定檔就選「開啟現有 .env」。第一次使用可在預設位置建立，或自選資料夾。偵測到 eKey 時會優先使用憑證所在資料夾，其他情況預設為使用者家目錄下的 .shioaji-pro。

        還沒有金鑰，可先看永豐開戶與申請教學。在永豐建立金鑰後，先保留顯示 Secret Key 的頁面，等兩組金鑰都填好並妥善儲存再關閉。

      2. 模擬下單

        按「執行 A 模擬下單測試」驗證台股。需要時可勾選期貨／選擇權或美股複委託。台股與期貨測試時段為週一至週五台灣時間 08:00–20:00，18:00 後限台灣 IP。測試期間請保持視窗開啟。

        首次完成模擬下單驗證後，建議等 30 分鐘，讓永豐處理 API 授權，再驗證或使用正式環境。

      3. 正式環境驗證

        使用已開啟「正式環境」權限的 API Key。憑證密碼預設為身分證字號（首字母大寫），曾改過請用新密碼。按「瀏覽…」選取憑證，再按「儲存憑證設定」及「執行 B 正式憑證測試」。可加查期貨／選擇權或美股複委託。

      4. 體驗 Shioaji Pro

        驗證通過後，開啟Shioaji Pro 官網。第一次登入時，選「從 .env 匯入」載入剛才驗證的設定檔。可用左側橘色「忘記設定檔.env在哪嗎?」複製路徑。

      結果怎麼看
      • 左側第一步顯示綠勾，代表金鑰已儲存且格式正確。登入結果以檢核表為準。
      • 檢核表會顯示「通過」、「未通過」、「未測」或「待確認」。委託若顯示「待確認」，請先查閱模擬環境的委託紀錄。
      • 金鑰登入驗證通過後，欄位會鎖定。需要更換時按「解鎖修改」，儲存後重新驗證。

      E2憑證密碼已填只跑 A 可忽略；要跑 B 必填
      E3憑證檔存在Sinopac.pfx 不在路徑指的位置
      A1模擬環境登入API Key 不存在／打錯、Secret Key 不成對、Key 過期、沒勾「行情/資料」
      A2證券帳戶這組 Key 底下沒有證券帳戶（沒開證券戶，或建 Key 時沒勾該帳戶）
      A3證券模擬下單沒勾「交易」、不在測試時段、證券 API 約定書未簽署
      A4／A5期貨帳戶／期貨模擬下單沒有期貨帳戶或期貨 API 約定書未簽署；只做證券可忽略（預設不測）
      A6／A7美股複委託帳戶／模擬下單請確認 API Key 已勾選複委託帳戶及交易權限。收到接受回報才算通過，驗證範圍限模擬環境。
      B1正式環境登入API Key 沒勾「正式環境」、金鑰錯誤
      B2證券 API 簽署狀態證券 API 約定書未簽署；尚未通過模擬驗證，或 API 授權還在處理；簽署時間晚於測試時間（重跑 A）
      B3期貨 API 簽署狀態期貨 API 約定書未簽署或期貨模擬測試沒做；只做證券可忽略
      B4憑證檔存在Sinopac.pfx 不在 SJ_CA_PATH 指的位置
      B5憑證啟用憑證密碼錯、憑證過期、憑證與帳號不符 → 到 API 管理頁重新下載
      B6憑證有效期說明欄會列出到期日與剩餘天數；已過期 → 重新下載；30 天內到期會提醒
      B7美股複委託帳戶簽署狀態請確認 API Key 勾選了複委託海外帳戶，並向永豐確認簽署狀態。
      換電腦與回報問題
      • 換電腦時，先安裝精靈，再透過安全方式搬移設定檔與憑證，或重新設定。若憑證路徑不同，在「正式環境驗證」重新選檔。
      • App 視窗開不起來時，確認系統有可用的瀏覽器。Windows 與 macOS 可使用 Microsoft Edge 或 Google Chrome 開啟獨立視窗。
      • 回報問題時，按右上「匯出除錯紀錄」。精靈會開啟檔案位置。紀錄會遮罩金鑰與憑證密碼，分享前請先檢查內容。
