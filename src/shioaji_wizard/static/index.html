    什麼時候跑：週一～五 08:00–20:00 台灣時間（18:00 後限台灣 IP；國定假日不算）。按下去前會先看你的時間與 IP。

    使用說明

    這個工具做什麼

    完成永豐 Shioaji API 開通必經的「模擬下單測試」，並確認正式環境的憑證可用。設定會存成本資料夾的 .env（SJ_API_KEY、SJ_SEC_KEY、SJ_CA_PASSWD、SJ_CA_PATH），和 Shioaji Pro／shioaji server 讀的是同一套名稱，之後可以直接沿用。

    先注意

    • 不要把這個資料夾放在 OneDrive／Google Drive／Dropbox／iCloud 等會自動同步的地方——.env（金鑰、憑證密碼）與 Sinopac.pfx（憑證本體）會被上傳。
    • 測試進行中不要關閉視窗。
    • .env 與 Sinopac.pfx 不要分享、不要上傳到任何地方。

    步驟

    1. 到 永豐金證券 API 管理頁 建立 API Key／Secret Key（權限至少「行情/資料」＋「交易」；要正式下單再加「正式環境」）。Secret Key 只顯示一次，先存好。
    2. 要正式下單的話，同一頁按「下載憑證」取得 Sinopac.pfx，下載時設定的密碼就是憑證密碼。把檔案放進本資料夾（或按「瀏覽」指定位置）。
    3. 在「金鑰與憑證」填入金鑰（與憑證密碼）→「儲存設定」。
    4. 執行 A。只在週一～五 08:00–20:00 台灣時間內測試才會被採計；通過後等約 1 分鐘。
    5. 執行 B，確認 signed=True、憑證密碼正確、憑證未過期。
    6. 看「檢核單」：每一項通過／未通過／未測與原因。

    畫面上的標示怎麼看

    • 輸入框顏色＝儲存狀態：綠＝已儲存在 .env、黃＝還沒填。一開始打字就變回一般樣式，清空又回到綠／黃。
    • 標籤前的圓圈＝最近一次測試對這一欄的結果：綠 ✓ 通過、紅 ✗ 卡在這欄（下方會有一行紅字原因）；沒驗過、或改過之後還沒再驗，就是空白。A 只會驗金鑰兩欄，B 才會驗憑證密碼與憑證檔。
    • 憑證檔欄留空＝使用同資料夾的 Sinopac.pfx；放別處就按「瀏覽…」。用 eLeader 申請的憑證預設在 C:\ekey\551\(身分證字號)\S（只有裝過 eLeader 的電腦才有；偵測到會提供「使用這個」一鍵帶入）。
    • 金鑰鎖定：A 或 B 通過後，API Key／Secret Key 會鎖起來（Secret Key 只會生成一次，避免誤觸）。只有要更換金鑰時才按「解鎖修改」，貼上新金鑰儲存後要重新跑 A。
    • 「也測期貨／選擇權」：整顆是切換鈕，按下變綠打勾、再按取消；只做證券不用按。
    • 進度軌（上方三站）：設定 → A → B，每站顯示目前狀態。

    檢核單代號與常見原因

    代號項目未通過的常見原因
    E1.env 格式／必填金鑰金鑰沒填、貼不完整、名稱大小寫錯、檔案不是 UTF-8
    E2憑證密碼已填只跑 A 可忽略；要跑 B 必填
    E3憑證檔存在Sinopac.pfx 不在路徑指的位置
    A1模擬環境登入API Key 不存在／打錯、Secret Key 不成對、Key 過期、沒勾「行情/資料」
    A2證券帳戶這組 Key 底下沒有證券帳戶（沒開證券戶，或建 Key 時沒勾該帳戶）
    A3證券模擬下單沒勾「交易」、不在測試時段、證券 API 約定書未簽署
    A4／A5期貨帳戶／期貨模擬下單沒有期貨帳戶或期貨 API 約定書未簽署；只做證券可忽略（預設不測）
    B1正式環境登入API Key 沒勾「正式環境」、金鑰錯誤
    B2證券 signed證券 API 約定書未簽署；A 還沒做／審核未完成（約 1 分鐘）；簽署時間晚於測試時間（重跑 A）
    B3期貨 signed期貨 API 約定書未簽署或期貨模擬測試沒做；只做證券可忽略
    B4憑證檔存在Sinopac.pfx 不在 SJ_CA_PATH 指的位置
    B5憑證啟用憑證密碼錯、憑證過期、憑證與帳號不符 → 到 API 管理頁重新下載
    B6憑證有效期已過期 → 重新下載；30 天內到期會提醒

    常見問題

    • 視窗開不起來：電腦需要 Microsoft Edge 或 Google Chrome（Windows 10/11 內建 Edge）。
    • 「shioaji 模組載入失敗」：安裝 Microsoft Visual C++ 可轉散發套件後重試。
    • 換電腦：整個資料夾複製過去即可；.env 與 Sinopac.pfx 自己帶或重新填。
    • 回報問題：按右上「匯出除錯紀錄」，本資料夾會多一個 shioaji_wizard-debug-日期.log（金鑰與憑證密碼已遮罩、身分證字號只留頭尾；仍含 IP 與帳號資訊，只給協助你的人）。
