## 支援純期貨帳戶模式

狀態：延後處理。

目前精靈以證券為必要商品；「也測期貨／選擇權」只會在證券測試之外追加期貨測試。
因此，現階段 B 缺少證券帳戶仍判定為失敗。

未來若支援只做期貨，需一併完成：

- 將 UI 改為可獨立選擇「證券」與「期貨／選擇權」，且至少選一種商品。
- A 模擬測試與 B 正式環境測試共用相同的商品選擇。
- 只有使用者選取的商品缺少帳戶時才判定失敗；未選商品標示為未測。
- 純期貨模式下，A2／A3 證券項目可為未測，A4／A5 期貨項目則必須通過。
- 純期貨模式下，B2 證券帳戶可為未測，B3 期貨帳戶則必須通過。
- 整體就緒狀態只依使用者選取的商品計算。
- 補齊證券限定、期貨限定、兩者皆選及未選商品的回歸測試。

本項目實作前，不更動目前「證券必要、期貨加選」的既有語義。
