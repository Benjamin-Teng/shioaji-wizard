# Shioaji 測試精靈交接

## 操作流程

桌面版沿用「跟著做」的四步驟。每次啟動從「設定金鑰」開始。使用者可開啟永豐下載的
`自訂名稱.env`、現有 `.env`，或選擇新檔位置。精靈記住實際選取的檔案，並將憑證
設定存回原檔，保留 `NAME`。偵測到 eKey 時，新建預設位置是憑證資料夾，否則為
`%USERPROFILE%\.shioaji-pro`。如果精靈找到目前設定檔對應的 eKey 憑證，且密碼
尚未儲存或輸入，會從憑證路徑帶入預設密碼。按「儲存憑證設定」才會寫入設定檔。
設定金鑰後可用左側橘色按鈕複製路徑。

Shioaji 1.8.0 的美股複委託可在模擬環境加測委託，在正式環境加查帳戶簽署狀態。
自動測試使用模擬回應。對永豐環境送出的模擬委託由使用者從 App 觸發。

桌面視窗預設為約 1248 × 680 邏輯像素的一般視窗。Windows 用一致的 DPI 座標
比較實際視窗與所在螢幕工作區，超出時才縮回可用範圍。

## 打包與宣傳頁

Windows 下載檔由 NSIS 產出。macOS 分 Apple 晶片與 Intel，兩種磁碟映像由
`macos-build.yml` 在對應架構建置與驗證。GitHub Pages 從 `main` 的 `docs/`
部署，依作業系統推薦 GitHub 最新版已上傳的安裝檔。截圖使用隔離設定的實際
桌面介面，畫面中的 Windows 使用者名稱以「使用者」呈現。

NSIS 依出貨清單解除安裝。啟動器需將執行資料放進安裝目錄的 `data`，並避免 Python
在程式目錄產生 bytecode，否則從開始選單啟動後，解除安裝會留下快取。發版驗收
包含 `--verify` 及啟動實際 Windows 開始選單捷徑後的解除安裝。

版本、安裝檔與校驗碼以 GitHub Release 為準。待辦與驗收證據記在 `kata list`。
