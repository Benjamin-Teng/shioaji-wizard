Shioaji 開通測試精靈

目前版本

依序設定金鑰、測試模擬下單、驗證正式帳戶與憑證，再把設定匯入 Shioaji Pro。支援台股，也可加測期貨／選擇權與美股複委託。

特色

每個步驟都有檢核結果

檢核結果會標出通過、未通過或未測。美股模擬委託若暫時沒有確認回報，會顯示「待確認」。

金鑰保存在本機

測試時由本機連接永豐官方 API。執行輸出和除錯紀錄會遮罩金鑰與身分證字號。

同一份設定可匯入 Shioaji Pro

可沿用現有 .env，也能自行選擇新建位置。預設優先使用偵測到的 eKey 憑證資料夾，其次是使用者目錄下的 .shioaji-pro。

安裝後直接啟動

安裝檔內建 Python 與所需套件。下載區會列出目前可用的 Windows 與 macOS 版本。

兩套測試，對應永豐開通流程

A 測試模擬登入與委託。B 檢查正式登入、帳戶簽署狀態與憑證，全程只查詢、不下單。

A模擬登入＋模擬下單測試

  • A1✓模擬環境登入（API Key／Secret Key）
  • A2✓證券帳戶
  • A3✓證券模擬下單（永豐金 2890 平盤價 1 張）
  • A4✓期貨帳戶（選測）
  • A5✓期貨模擬下單（選測）
  • A6✓美股複委託帳戶（選測）
  • A7✓美股複委託模擬限價單（選測）

首次完成模擬下單驗證後，建議等 30 分鐘，讓永豐處理 API 授權，再驗證或使用正式環境。

B正式環境憑證測試

  • B1✓正式環境登入
  • B2✓證券 API 簽署＋模擬測試審核（signed）
  • B3✓期貨 API 簽署狀態（選測）
  • B4✓憑證檔存在（Sinopac.pfx／SJ_CA_PATH）
  • B5✓憑證啟用（憑證密碼）
  • B6✓憑證有效期（顯示到期日）
  • B7✓美股複委託帳戶簽署狀態（選測）

密碼錯、路徑錯、金鑰打錯字，各自會有明確的中文原因，不用看英文錯誤訊息猜。

精靈的四個步驟

  1. 設定金鑰。選取已有的 .env，或填寫 API Key 和 Secret Key 建立新設定。
  2. 模擬下單。驗證台股模擬委託，可加測期貨／選擇權與美股複委託。
  3. 正式環境驗證。選擇憑證檔並填入密碼，檢查正式登入、帳戶簽署狀態與憑證。
  4. 體驗 Shioaji Pro。首次登入時選「從 .env 匯入」，載入剛才驗證的設定檔。開啟 Shioaji Pro 官網

還沒有金鑰？先看永豐申請教學。Secret Key 只會顯示一次，複製並妥善儲存後再關閉頁面。

常見問題

Windows 顯示 SmartScreen 提示怎麼辦？

先確認安裝檔來自本專案的 GitHub Release，並與該頁公布的 SHA-256 對照。若安全軟體仍攔截，請附上警示名稱到 GitHub Issues 回報。

需要先裝 Python 或其他東西嗎？

安裝檔已內建 Python 與所需套件。Windows 版支援 Windows 10／11（x64）。下載 macOS 版前，可從 Apple 選單的「關於這台 Mac」查看你的電腦使用 Apple 晶片或 Intel 處理器。

資料夾可以放在 OneDrive／Google 雲端硬碟裡嗎？

請將 .env 與憑證存在本機不會同步的資料夾，避免同步軟體上傳或鎖住這些檔案。

測試失敗要怎麼回報？

點選「匯出除錯紀錄」取得經遮罩的 shioaji_wizard-debug-*.log，再到 GitHub Issues 回報。請勿附上 .env 或憑證檔。

舊版的設定可以沿用嗎？

在第一步選「開啟現有 .env」，選取舊版正在使用的設定檔。正式環境驗證時可另外選擇原有的憑證。
